📋 Advanced Excel Formulas for 3-Way Analysis

Use these formulas to create your own 3-way reconciliation matrix:

Coverage Status Formula:

=IF(AND(NOT(ISERROR(VLOOKUP(A2,NCentralList,1,FALSE))),NOT(ISERROR(VLOOKUP(A2,ADList,1,FALSE))),NOT(ISERROR(VLOOKUP(A2,AVList,1,FALSE)))),"FULLY COVERED",IF(OR(NOT(ISERROR(VLOOKUP(A2,NCentralList,1,FALSE))),NOT(ISERROR(VLOOKUP(A2,ADList,1,FALSE))),NOT(ISERROR(VLOOKUP(A2,AVList,1,FALSE)))),"PARTIAL COVERAGE","NOT FOUND"))

PowerShell 3-Way Analysis Script:

# RMS 3-Way Device Reconciliation Script $NCentralDevices = Get-Content "NCentralDevices.txt" | ForEach-Object { $_.Trim().ToUpper() } $ADDevices = Get-Content "ADDevices.txt" | ForEach-Object { $_.Trim().ToUpper() } $AVDevices = Get-Content "AVDevices.txt" | ForEach-Object { $_.Trim().ToUpper() } $AllDevices = ($NCentralDevices + $ADDevices + $AVDevices) | Sort-Object -Unique $Results = @() foreach ($Device in $AllDevices) { $InNCentral = $Device -in $NCentralDevices $InAD = $Device -in $ADDevices $InAV = $Device -in $AVDevices $CoverageStatus = if ($InNCentral -and $InAD -and $InAV) { "FULLY COVERED" } elseif ($InNCentral -or $InAD -or $InAV) { "PARTIAL COVERAGE" } else { "NOT FOUND" } $Results += [PSCustomObject]@{ DeviceName = $Device NCentral = $InNCentral ActiveDirectory = $InAD Antivirus = $InAV CoverageStatus = $CoverageStatus } } $Results | Export-Csv "3Way_Device_Analysis.csv" -NoTypeInformation Write-Host "Analysis complete. Total devices analyzed: $($AllDevices.Count)" -ForegroundColor Green
